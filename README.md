### Hi there 👋 I'm Dan

I build open-source tools that make hard things simple. Two projects of mine:

#### 📱 [IPAForge](https://github.com/IPAForge/ipaforge)

The new generation of sideloading: a free, open-source desktop app that installs SideStore and your own apps on iPhone and iPad with a free Apple ID, from Windows, macOS and Linux. Its whole engine, code signing included, is written in TypeScript, and every release is Sigstore-signed.

🌐 [Website](https://ipaforge.github.io) · ⬇️ [Download](https://github.com/IPAForge/ipaforge/releases) · 💬 [Discord](https://discord.gg/C87DKmAWhr) · 🗺️ [Roadmap](https://github.com/IPAForge/ipaforge/blob/main/docs/roadmap.md)

#### 🎮 [Big Brother Bot (B3) 2.0](https://github.com/SirReaDy/BigBrotherBot)

The new generation of B3, the game-server admin bot: a ground-up rewrite of the classic Python 2.7 bot in modern, fully typed, `asyncio` Python 3.11+, with one validated YAML config, SQLAlchemy and migrations, plugins that install by name, and `b3 doctor` for straight answers when something is misconfigured.

📖 [Documentation](https://sirready.github.io/BigBrotherBot/) · 🎯 [Call of Duty 4 status dashboard](https://github.com/SirReaDy/cod4-status-server)
