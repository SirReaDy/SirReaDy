### Hi there 👋 I'm Dan

**Author of [IPAForge](https://github.com/IPAForge/ipaforge)**, the new generation of sideloading: a free, open-source desktop app that installs SideStore and your own apps on iPhone and iPad with a free Apple ID, from Windows, macOS and Linux. Its whole engine, code signing included, is written in TypeScript, and every release is Sigstore-signed.
